# design.md — "Things in the Classroom" Spinner Wheel

Build instructions for a coding agent. Read the whole file before writing code. You cannot see images, so every visual detail is described in text. Follow the numbers and hex colors exactly.

## 1. Goal

A simple, kid-friendly web page for Grade 2 elementary students (Indonesia) learning English classroom vocabulary.

- A colorful wheel with 8 wedges. Each wedge shows a picture of a classroom object and its English name.
- The teacher or student presses **Spin**. The wheel rotates and stops on one random object.
- A large pop-up then shows the picture and word big, with a speaker button that says the word aloud.
- Client asked for "simple". Do not add features that are not listed here.

## 2. Tech constraints

- Plain **HTML + CSS + vanilla JavaScript**. No frameworks, no build step, no npm, no external CDN, no web fonts, no external images.
- Must work by double-clicking `index.html` (file://), fully offline.
- Do NOT use ES modules (`type="module"`), `fetch`, or anything that breaks under file://. Use a normal `<script src="script.js" defer>`.
- The wheel is drawn with **inline SVG generated by JavaScript** (not canvas, not PNG).
- Object pictures are **inline SVG icons** defined in the code (section 6). Do not use emoji.
- Speech uses the browser `speechSynthesis` API (section 9).

## 3. Files

## 5. Visual design

### 5.1 Page

- Background: soft cream `#FFF8EC`. Page is a single centered column, no scrolling on a 360x640 phone or a 1366x768 laptop.
- Font stack for everything: `"Nunito", "Quicksand", "Trebuchet MS", system-ui, sans-serif`. Headings and wheel labels bold (700–800).
- Text color: `#2D2D2D`.
- Top: `<h1>` "Things in the Classroom" (center, 800 weight, clamp 24px–40px). Under it a subtitle "Spin the wheel and say the word!" (clamp 16px–22px, color `#6B6B6B`).
- Middle: the wheel with a fixed pointer.
- Bottom: one big **SPIN** button.

### 5.2 Wheel geometry (SVG)

Use `viewBox="0 0 600 600"`. Center = (300, 300). The `<svg>` scales to a CSS width of `min(90vw, 62vh, 560px)`, square (`aspect-ratio: 1`).

Layers from back to front:

1. **Outer frame circle:** r = 296, fill `#FFFFFF`, stroke `#2D2D2D` at 25% opacity, stroke-width 2. Plus a soft drop shadow (CSS `filter: drop-shadow(0 8px 16px rgba(0,0,0,.18))`).
2. **Wedges:** a rotating group `<g id="wheel">` containing all wedges. Each wedge is an annular sector between r = 95 and r = 290 (ring shape that leaves the hub area free), filled with its color, separated by 3px white strokes (`stroke="#fff" stroke-width="3"`).
3. **Hub (center, part of the rotating group):** circle r = 95 fill `#FFFFFF`, then on top a white rounded octagon-like shape is NOT required; a plain white circle is enough. In the hub put the text, centered at (300,300), two lines, font-size 22, weight 800, fill `#2D2D2D`: line 1 "Things", line 2 "in the classroom" (font-size 16, weight 700). Hub text rotates with the wheel (it is inside the group) — acceptable. Also a thin ring: circle r = 95 fill none stroke `#2D2D2D` stroke-opacity .15 stroke-width 2.
4. **Pointer (does NOT rotate):** a triangle fixed at the top, tip pointing DOWN into the wheel. Points: (270, 0), (330, 0), (300, 44). Fill `#E8505B`, stroke `#fff` width 4, stroke-linejoin round. The tip overlaps the top of the wheel at (300, 44).

### 5.3 Wedge construction

For wedge index `i` of `n`:

- `step = 360 / n`
- `center angle = i * step` (degrees clockwise from the top)
- `start = center - step/2`, `end = center + step/2`
- Convert polar to cartesian with the top as 0°: `x = 300 + r * sin(a)`, `y = 300 - r * cos(a)` (a in radians).
- Path: move to outer start, arc along r = 290 to outer end (sweep-flag 1, large-arc 0), line to inner end at r = 95, arc back along r = 95 to inner start (sweep-flag 0), close.

So wedge 0 is centered exactly at the top, directly under the pointer when the wheel rotation is 0.

### 5.4 Content inside each wedge

Draw each wedge's content inside a `<g>` with `transform="rotate(centerAngle 300 300)"`, designed as if the wedge were at the top, then it rotates into place. (Content therefore points outward along the wedge radius; the wheel spins, so any orientation will pass the top.)

Designed for the top position (wedge centered at x = 300):

- **Word label:** `<text>` at x = 300, y = 62 (outer ring, near r ≈ 238), `text-anchor="middle"`, `dominant-baseline="middle"`, font-size 26, weight 800, fill `#2D2D2D`, `letter-spacing: 0.5px`. Label must fit inside the wedge: "pencil case" is the longest; if it overflows, use `textLength` capped at 150 with `lengthAdjust="spacingAndGlyphs"`. Show the word in lowercase exactly as in the table.
- **Icon:** a 72x72 icon centered at (300, 150) (i.e. `x=264 y=114 width=72 height=72`), using `<use href="#icon-ID">` with symbols from section 6. Place a white circle r = 40 at (300,150) with opacity .55 behind the icon so it pops from the wedge color.

## 8. Spin logic

State: `currentRotation` (number, degrees, cumulative, starts at 0) and `isSpinning` (boolean).

On click of SPIN (or Space/Enter when the button is focused):

1. If `isSpinning`, return. Set `isSpinning = true`, disable the button.
2. Pick `k = random integer in [0, n)`.
3. Wedge k's center is at angle `k * step` on the wheel. To bring it under the pointer, the final rotation modulo 360 must equal `(360 - k * step) % 360`.
4. Add a small random offset inside the wedge so it doesn't always stop dead-center: `jitter = (Math.random() - 0.5) * step * 0.6`.
5. Choose extra full turns: `turns = 5 + Math.floor(Math.random() * 3)` (5–7).
6. `base = currentRotation - (currentRotation % 360)` (start of the current turn). `target = base + turns * 360 + ((360 - k * step) % 360) + jitter`. Ensure `target > currentRotation + 360 * 3`; if not, add 360.
7. Apply to the `#wheel` group via CSS: `transition: transform 4.2s cubic-bezier(0.17, 0.67, 0.12, 0.99); transform: rotate(<target>deg); transform-origin: 300px 300px;` (use `transform-box: view-box` or set origin explicitly so rotation is about the SVG center).
8. Set `currentRotation = target`. Never reset to 0 (avoids rewinding animation).
9. On the `transitionend` event of `#wheel` (filter `event.propertyName === "transform"`), set `isSpinning = false`, enable the button, and open the result modal for item `k`. Add a fallback `setTimeout` of duration + 300ms in case `transitionend` doesn't fire.
10. Respect `prefers-reduced-motion: reduce`: use a 1s duration and 1 extra turn.

The item shown in the modal must be item `k` (the chosen index), never computed from the final angle.

## 9. Result modal

Opens after the wheel stops.

- Full-screen overlay `rgba(0,0,0,.45)`, centered card, white, border-radius 28px, padding 28px, width `min(88vw, 420px)`, subtle pop-in animation (scale .85 → 1, 200ms). Disabled under reduced motion.
- Card top: a color band or circle using the wedge's color (circle 200px, fill = wedge color) with the icon (`<use href="#icon-ID">`) at 140x140 inside.
- Word: the label in 56px weight 800 (clamp 40px–56px), centered, color `#2D2D2D`.
- Speaker button: round 56px button with an inline SVG speaker icon (not emoji), `aria-label="Hear the word"`. Clicking it speaks the word.
- Primary button "Spin again" (same style as SPIN button, smaller): closes the modal and immediately starts a new spin.
- Secondary text button "Close" (plain, color `#6B6B6B`): closes the modal only.
- Close also on: overlay click, `Escape` key.
- Accessibility: `role="dialog"`, `aria-modal="true"`, `aria-labelledby` pointing at the word element. Move focus to the "Spin again" button on open; return focus to the SPIN button on close.

Speech:

```js
function speak(text) {
  if (!("speechSynthesis" in window)) return;
  window.speechSynthesis.cancel();
  const u = new SpeechSynthesisUtterance(text);
  u.lang = "en-US";
  u.rate = 0.8;   // slow, clear for kids
  u.pitch = 1.1;
  window.speechSynthesis.speak(u);
}
```

If `speechSynthesis` is unsupported, hide the speaker button.

## 10. Responsive behavior

- Mobile portrait (360–430px wide): wheel `90vw`, header compact, button below the wheel, everything visible without scrolling.
